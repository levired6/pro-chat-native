# Pro Chat Native

A professional real-time chat application built with **React Native**, **Expo**, and **Firebase**.

## 🚀 Features

- **Anonymous Authentication:** Quickly join the chat without complex signups.
- **Real-time Messaging:** Powered by Google Firestore for instant updates.
- **Custom UI:** Users can choose their preferred background color for the chat interface.
- **Modern Design:** Glassmorphism UI elements and professional color palettes.

## 🛠️ Setup Instructions

1. **Clone the repository:**
   `git clone https://github.com/YOUR_USERNAME/pro-chat-native.git`
2. **Install dependencies:**
   `npm install`
3. **Firebase Configuration:**
   Create a `firebaseConfig.js` in the root directory and add your Firebase project credentials.
4. **Start the App:**
   `npx expo start`
